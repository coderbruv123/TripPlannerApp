# TripPlannerApp 🚗✈️

A travel planning app built with **React + TypeScript** and **ASP.NET Core** .

## Current Features

* Destination search
* Trip planning with travelers, dates, and budget
* Driving, walking, and cycling routes
* Bus route estimation
* Interactive MapLibre map
* Route visualization

## Tech Stackhttps://github.com/coderbruv123/TripPlannerApp/blob/main/README.md

* React + TypeScript
* Tailwind CSS
* ASP.NET Core / C#
* MapLibre
* OpenRouteService
