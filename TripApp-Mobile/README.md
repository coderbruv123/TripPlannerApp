# TripApp Mobile

Basic Expo + TypeScript starter for the TripPlanner mobile app.

## Prerequisites

- [Node.js](https://nodejs.org/) (LTS recommended)
- npm
- [Expo Go](https://expo.dev/go) on your iOS or Android device, or an emulator/simulator

## Run

From `TripApp-Mobile/`:

```bash
npm install
npx expo start
```

Then:

- **Expo Go:** Scan the QR code shown in the terminal.
- **Android emulator:** Press `a` in the Expo CLI.
- **iOS simulator:** Press `i` in the Expo CLI (macOS only).
- **Web:** Press `w` in the Expo CLI.

## Useful check

```bash
npx tsc --noEmit
```
